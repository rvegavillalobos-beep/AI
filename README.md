# 🐦 Flappy Bird + NEAT en Streamlithttps://github.com/rvegavillalobos-beep/AI/tree/main

Agente que aprende a jugar Flappy Bird usando un algoritmo genético (NEAT).

## Ejecutar localmente
pip install -r requirements.txt
streamlit run app.py

## Desplegar en Streamlit Cloud
1. Sube este repositorio a GitHub.
2. Entra a share.streamlit.io y conecta el repo.
3. Selecciona `app.py` como archivo principal.
